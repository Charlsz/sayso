# Professional communication

Read this for workplace email, memos, and messages to colleagues, candidates, customers, or vendors.

The standard is a clear, courteous message a recipient can act on. Normal capitalization and complete sentences are the default. Follow a different register only when the user writes that way or asks for it.

- Put the decision, request, or news in the first sentences. The subject line should say the same thing.
- Include only the facts the user provided. Do not invent rapport, praise, history, titles, or a last name.
- State a refusal, delay, or change so it cannot be read as agreement. Courtesy should be real and short. Extra apologies that blur the decision should come out.
- Say what happens next only when the user said what happens next.
- A message whose job is sympathy, thanks, or bad news can be warmer and longer. The thing to remove is padding, not the human part.
- Match the form they asked for. An email can have a subject and a short body. A chat message to a coworker does not need a letterhead.
